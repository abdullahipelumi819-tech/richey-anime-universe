# Richey Anime Universe

Richey Anime Universe is an original anime/fantasy story project built around emotional characters, mystery, action and unusual cultivation systems.

## Stories

1. **The World That Forgot Richey** — Echo Path
2. **Chaos Lord** — Chaos Path
3. **The Crown of No One** — Throne Path
4. **The Girl Who Stole Tomorrow** — Chrono Bloom
5. **The Sea Beneath the Sky** — Abyssal Tide
6. **The Nameless Sword Saint** — Intent Path
7. **When Shadows Learned to Pray** — Umbral Faith
8. **The City That Dreams in Metal** — Soulcraft Path
9. **Seven Suns of Ruin** — Solar Ruin Path
10. **The Last God Without a Name** — Null Path

The cancelled third-story concept **The Awakening of Richey** has been removed as requested. Richey's main story remains **The World That Forgot Richey**.
